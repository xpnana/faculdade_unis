## Atividade Ciclo 1 - Hello World (Python 2.x vs 3.x)

Esta atividade consistiu na implementação do clássico "Hello World" utilizando duas gerações diferentes da linguagem Python para compreender as mudanças de sintaxe.

##  Pré-requisitos para Validação
Para executar e validar ambos os scripts localmente, **é necessário ter as duas versões do Python instaladas** na sua máquina:
* Python 2.x
* Python 3.x

##  Como executar no PyCharm
Como os arquivos dependem de interpretadores diferentes, a troca de versão foi feita manualmente no PyCharm:

1. **Para rodar o `HelloWorld_v2x.py`:**
   * Vá em `File` > `Settings` (ou `Preferences` no Mac) > `Project: LP_UNIS_Atividades` > `Python Interpreter`.
   * Altere o interpretador para a versão do **Python 2.x**.
   * Execute o script.

2. **Para rodar o `HelloWorld_v3x.py`:**
   * Volte no mesmo menu de `Python Interpreter`.
   * Altere o interpretador para a versão do **Python 3.x**.
   * Execute o script.
