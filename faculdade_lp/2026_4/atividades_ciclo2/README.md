# Atividades Ciclo 2 - Exercícios Práticos

Este módulo contém uma série de 5 exercícios de lógica e manipulação de dados desenvolvidos como parte da disciplina de Linguagem de Programação.

## Ambiente de Desenvolvimento
* **IDE:** PyCharm
* **Versão do Python:** 3.7

## Relação de Exercícios

* **`Atividade_1.py`:** Conversão de idade expressa em dias para o formato de anos, meses e dias.
* **`Atividade_2.py`:** Verificador de existência de triângulos e cálculo de área com base em 3 valores inteiros positivos.
* **`Atividade_3.py`:** Algoritmo para ler 3 números inteiros e identificar o menor deles.
* **`Atividade_4.py`:** Função verificadora de números primos aplicada em um intervalo de 1 a 100.
* **`Atividade_5.py`:** Função de manipulação de strings que recebe uma frase e inverte as letras de cada palavra individualmente.

## Como Executar
1. Certifique-se de que o PyCharm está configurado para utilizar o interpretador **Python 3.7** (`Settings` > `Python Interpreter`).
2. Clique com o botão direito sobre o arquivo da atividade que deseja testar e selecione **`Run 'Atividade_X'`**.
